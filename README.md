### 🚀 Featured Projects

<details>
<summary><b>🧑‍🤝‍🧑 CollabBoard — Real-Time Collaborative Whiteboard</b></summary>
<br/>

Multiplayer whiteboard delivering real-time collaboration through Yjs CRDT over Socket.io — the same conflict-free sync class of algorithm used by Figma and Notion — with custom binary protocol bridging and production-grade auth.

| | |
|---|---|
| **Stack** | React 18 · Node.js · MongoDB · Socket.io · Yjs CRDT · Fabric.js · JWT |
| **Scale** | 10 drawing tools · 60-step undo/redo · live cursor broadcast at 30 fps |
| **Performance** | Canvas sync under 100ms per user · 5-min garbage collection for idle rooms |
| **Security** | HttpOnly cookie refresh tokens, automatic rotation, reuse-detection wiping sessions on suspected theft |
| **Impact** | Zero-downtime rolling deploys via GitHub Actions CI/CD across Vercel + Railway + MongoDB Atlas |
| **Repository** | [github.com/yug-24/collabboard](https://github.com/yug-24/collabboard) · [Live Demo](https://collabboard.vercel.app) |

Engineered a custom `SocketYjsProvider` bridging y-protocols over Socket.io binary frames, enabling conflict-free real-time editing with PNG (2×) and SVG export, debounced auto-save, and persistent Yjs state.

</details>

<details>
<summary><b>📊 DevPulse — GitHub Analytics SaaS Dashboard</b></summary>
<br/>

SaaS-style analytics dashboard built on GitHub OAuth 2.0, surfacing contribution heatmaps, streak tracking, language breakdowns, and PR velocity through a combined REST + GraphQL data layer.

| | |
|---|---|
| **Stack** | React 18 · Node.js · MongoDB · Passport.js · GitHub OAuth 2.0 · GraphQL · Recharts |
| **Scale** | 365-day contribution heatmap · language aggregation across 20 repos in parallel |
| **Performance** | Two-layer cache (NodeCache 5-min TTL → MongoDB 30-min TTL) · ~90% fewer API calls · sub-200ms dashboard loads |
| **Security** | Per-route rate limiting, JWT HttpOnly sessions, server-side GitHub token encryption |
| **Impact** | Raw GitHub token never reaches the browser — full server-side custody of sensitive credentials |
| **Repository** | [github.com/yug-24/devpulse](https://github.com/yug-24/devpulse) · [Live Demo](https://devpulse-yug24.vercel.app) |

Used GraphQL specifically for contribution calendar data unavailable via REST, and `Promise.allSettled()` to parallelise language aggregation without letting single-repo failures break the dashboard.

</details>
